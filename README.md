# Hindi Alphabet Learning Website

## Overview
This is an interactive website designed to teach Hindi alphabets and their sounds. The website provides a beautiful and engaging interface for learners to explore the Hindi alphabet (Devanagari script), listen to pronunciations, and practice through interactive exercises.

## Features

### 1. Alphabet Exploration
- Visual cards for all Hindi vowels (स्वर) and consonants (व्यंजन)
- Interactive flip cards showing pronunciation guides and examples
- Audio pronunciation for each letter (simulated in the current version)

### 2. Practice Exercises
- Listening Exercise: Listen to a sound and identify the correct Hindi letter
- Matching Exercise: Match Hindi letters with their correct transliterations

### 3. Responsive Design
- Works on desktop, tablet, and mobile devices
- Beautiful gradient color scheme and animations

## How to Use

1. **Exploring Alphabets**:
   - Click on any alphabet card to hear its pronunciation and see examples
   - Cards will flip to show additional information and examples

2. **Listening Exercise**:
   - Click "Play Sound" to hear a random Hindi letter
   - Select the correct letter from the options provided
   - Receive immediate feedback on your answer

3. **Matching Exercise**:
   - Click "Start Matching" to begin the exercise
   - Match Hindi letters with their correct transliterations
   - Complete all matches to win the game

## Technical Notes

- Built with HTML5, CSS3, and vanilla JavaScript
- No external libraries or frameworks required
- Simulated audio playback (in a production version, actual audio files would be added)
