# Hindi Alphabet Sounds

This directory is intended for storing audio files for the Hindi alphabet learning website.

## Audio Files Naming Convention

### Vowels
- a.mp3 - अ
- aa.mp3 - आ
- i.mp3 - इ
- ee.mp3 - ई
- u.mp3 - उ
- oo.mp3 - ऊ
- ri.mp3 - ऋ
- e.mp3 - ए
- ai.mp3 - ऐ
- o.mp3 - ओ
- au.mp3 - औ
- am.mp3 - अं
- ah.mp3 - अः

### Consonants
- ka.mp3 - क
- kha.mp3 - ख
- ga.mp3 - ग
- gha.mp3 - घ
- nga.mp3 - ङ
- cha.mp3 - च
- chha.mp3 - छ
- ja.mp3 - ज
- jha.mp3 - झ
- nya.mp3 - ञ
- etc.

## Audio File Requirements

- Format: MP3
- Clear pronunciation by a native Hindi speaker
- Short duration (1-2 seconds per sound)
- Consistent volume levels across all files

In a production environment, replace this file with actual audio recordings of each Hindi alphabet sound.
